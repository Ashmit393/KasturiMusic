KASTURI MUSIC PLAYER

Simple, sundar aur poori tarah offline music player. Koi ads nahi, koi login nahi, koi tracking nahi.

Download APK

Android 8.0 ya usse naya phone chahiye

Install kaise karein

  1. Upar Download APK dabayein.
  2. Download hone ke baad file kholein.
  3. Agar Android permission maange, to "Allow from this source" chalu karein.
  4. Install dabayein, phir app kholein aur music access Allow karein.

Zaroori baat

Yeh app Play Store par nahi hai, isliye Android ek warning dikha sakta hai. Yeh normal hai.
